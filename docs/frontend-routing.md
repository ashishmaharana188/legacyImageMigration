# Frontend Routing

This document outlines the frontend routing setup for the PDF Processor application, implemented using TanStack Router.

## Overview

The frontend routing is managed by `@tanstack/react-router`, a fully type-safe routing library for React. It allows for a file-based routing convention, where routes are defined by creating files in the `frontend/src/routes` directory.

## Key Components

-   **`@tanstack/react-router`**: The core routing library.
-   **`frontend/src/main.tsx`**: The application entry point, where the router is initialized and the `RouterProvider` is rendered.
-   **`frontend/src/routes`**: The directory containing all route definitions.
-   **`frontend/src/routes/__root.tsx`**: The root route of the application. It defines the root layout and renders an `Outlet` for nested routes.
-   **`frontend/src/App.tsx`**: The main application component, which serves as the root layout. It contains the `Sidebar` and the main content area where the `Outlet` renders the matched route component.
-   **`frontend/src/components/ui/Sidebar.tsx`**: The sidebar component, which uses the `Link` component from `@tanstack/react-router` for navigation.

## Route Definitions

Routes are defined by creating files in the `frontend/src/routes` directory. Each file exports a `Route` component created using `createFileRoute`.

-   `/`: `frontend/src/routes/index.tsx` (Home page)
-   `/upload-script`: `frontend/src/routes/upload-script.tsx`
-   `/sql-mongo`: `frontend/src/routes/sql-mongo.tsx`
-   `/sanity-check`: `frontend/src/routes/sanity-check.tsx`
-   `/s3-browser`: `frontend/src/routes/s3-browser.tsx`

## Route Generation

The `routeTree.gen.ts` file, which is essential for the router to function, is automatically generated by running the following command:

```bash
npm run generate-routes
```

This command uses the `@tanstack/router-cli` to scan the `frontend/src/routes` directory and generate the route tree.

## Navigation

Navigation between routes is handled by the `Link` component from `@tanstack/react-router`. The `Sidebar` component uses `Link` components to navigate to the different task pages.

## Adding a New Route

To add a new route:

1.  Create a new component for the page (e.g., `frontend/src/components/action/MyNewTask.tsx`).
2.  Create a new file in the `frontend/src/routes` directory (e.g., `frontend/src/routes/my-new-task.tsx`).
3.  In the new route file, define the route using `createFileRoute` and import the component.
4.  Run `npm run generate-routes` to update the route tree.
5.  Add a new `Link` to the `Sidebar` component to navigate to the new route.
